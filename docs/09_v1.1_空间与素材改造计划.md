# v1.1 空间与素材改造计划

日期：2026-10-08。原版 `bubu-yier-cozy-home` 保留不动；新版本在同级 `bubu-yier-cozy-home-v1.1` 实施。

## 验收契约

- 交付：可运行三区域家园、地图拖动与区域近景、分散的24项装修、可操作家园互动、重新生成的36种物品与6个生产器、24件新装修素材、鲜明合成反馈；构建部署版与完整离线单文件。
- 固定边界：布布一二外形以 `art/reference/bubu.png` 和 `yier.png` 为准；任何包含二者的生图均带入两张角色卡。原版、参考原件不改。保留49格二合、六链六阶、24项主线、现有经济与旧存档兼容。
- 配色与质感：参考用户 `ChatGPT 图像 2026年10月8日 08_46_33.png` 的明亮花园色彩；通用物品采用原创圆润、夸张的3D玩具体积感与高光。角色保留卡片中的轮廓与身份特征。
- 非目标：本轮不接广告、支付、联网好友或发布平台；不扩张为无限剧情或新货币体系。
- 完成条件：三个区域可进入与返回，装修前后状态正确，互动有真实状态和反馈，图像实际接入棋盘/图鉴/订单/家园/照片，旧存档可恢复；通过规则、构建、相关UI及视觉复核，并准确注明不可验证项。

## 实施顺序与责任

1. 主代理：保留原版、制作图像与角色参考记录、整合、运行与视觉验收。
2. 规则代理：区域数据、装修重新布局、家园互动与存档迁移、相关规则回归。
3. UI代理：可拖动全景地图、区域近景、三区域操作、鲜明棋盘、合成反馈、照片导出。
4. 素材运行代理：透明图集映射、CSS与Canvas取图接口、构建资源列表和版本入口。

## 图像生产规格

所有透明图集采用3列2行、按阅读顺序六个独立物件。直接通过CSS视口和Canvas源矩形读取整张图集，不通过程序替代生图或修改画面。

- atlas-clean / tools / bake / tea / craft / garden：六条链各六阶，共36件新物品。
- atlas-generators：清洁篮、修理箱、小烤箱、泡茶台、画画箱、园艺篮。
- atlas-decor-a/b/c/d：24项装修的独立物件；对应原有改造阶段，室外物件移至花园和庭院。
- region-house / region-garden / region-courtyard：不含角色的三块近景空间。
- world-map：不含角色的宽阔家园全景。
- party-memory：角色卡参考的双熊聚会画面，用于兑现终章。
- yier-rest：角色卡参考的一二休息动作，用于第五章回忆。

## 验证原则

只运行与地图、素材、互动、存档和主线兼容直接相关的检查。浏览器若因权限故障无法访问，应报告限制，不通过替代控制方式绕过；规则与构建继续进行。模拟推进时间不代表真人时长，桌面视口不代表真机。

## 决策账本

- 将24件装修分摊到小屋、花园、庭院，给每个区域保留角色活动空间。
- 保留现有剧情与经济，新增互动复用现有资源；不以缩紧体力增加刺激。
- 新通用素材用实际生图替换运行视觉，旧素材仅作为原版资料保留。
- 完成小屋、花园、庭院的真实区域操作；全景本身不代替玩法。
