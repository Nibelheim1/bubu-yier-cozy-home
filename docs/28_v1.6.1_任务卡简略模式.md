# v1.6.1 任务卡简略模式

合成页的主线、邻里委托和茶会卡默认采用简略模式。卡片只展示所需物品的图片、等级和持有/需求数量，不显示任务名称、剧情、类别、阶段、奖励或操作按钮。材料较多时按三列换行，全部需求可见；横排保持三张卡同时显示，其余卡片可横滑查看。

点击物品卡打开完整任务详情，查看愿望、阶段与奖励，进行交付、认识材料来源、更换邻里委托或选择茶会方案。详情内点击单件物品仍可查看六阶合成路线。关闭详情回到简略模式，不改变存档和物资。

未开放的邻里与茶会提示卡不再占用合成页卡位。删除工作台标题与棋盘之间的说明行及对应闲置渲染函数、样式。保留工作台工具、棋盘底部选中物品信息、提示按钮与玩法说明。

交付主线阶段后详情立即更新为下一阶段，不提前发放奖励。更换委托后详情立即绑定新委托；成功交付支线后关闭详情并展示新的简略卡片，避免留在过期订单中。

版本升级保留96项主线、循环支线、体力规则及原存档键；没有更改任务和经济数据。
