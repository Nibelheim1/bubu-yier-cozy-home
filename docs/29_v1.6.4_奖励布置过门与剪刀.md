# v1.6.4 奖励、布置、过门与剪刀

1. 简略任务卡左下角显示心愿星、金币、经验的奖励缩略图及数量。使用绝对定位叠放在原卡片内，不增加宽度或高度，不完全遮挡材料图；分阶段主线显示的是整单奖励，详情保留具体发放说明。
2. 修复“可以布置啦”和“下一个小愿望”按下时跳位：全局按钮的按下位移曾覆盖家具按钮的居中位移，导致释放时落点跑出按钮。现在保留居中定位，并取消就绪按钮的上下浮动。未备齐时打开当前主线详情，备齐后打开布置确认。
3. 新家具待布置卡显示在家园标题下、全景和场景之前，并在页面滚动时保持在顶部；只出现一张。点击卡片即可布置到对应场景。
4. 随机行走走入现有椭圆门区时自动传送。同场景时，每次行走有30%概率选门；分场时提高到75%，优先选通往同伴的门，小屋与花园之间经庭院。追随路线使用运行态预约，降低对向错过；过门后冷却18秒并停留4–6秒。位置保存，镜头不跟随自动跳转；陪伴与首访入口同步更新。手动拖动过门仍可立即使用。
5. 点击普通物品后显示“剪刀 ×余量”入口，选项内显示“使用剪刀 · 剩余N把”。使用1把拆成两个低一级物品；无剪刀、一级物品、满棋盘或新手阶段禁用并显示原因，失败不扣剪刀。绑定所选棋盘格，避免错误拆分其他物品。

页面验证还发现，旧点击保护会误拦截选择棋盘物品后的快速选项点击。现在新的指针按下代表主动操作，仅拖动结束产生的残余点击被抑制。
