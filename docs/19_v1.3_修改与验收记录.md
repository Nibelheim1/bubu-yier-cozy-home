# 熊熊之家 v1.3.0 修改与验收记录

日期：2026-10-09。交付为当前目录的 `dist/` 和 `release/熊熊之家_双击即玩.html`，已有启动文件继续可用。项目目录保留v1.2名称，实际游戏与构建版本为1.3.0。

## 验收范围

本轮完成房间/庭院时间天气变化、两熊自主活动与动作GIF、可布置提示统一入口、对白头像。保留当前已完成的“熊熊之家”更名、平面角色、小栗独立形象、合成与家具移动逻辑。存档键仍为v1.2，schema仍为2，不改配方、奖励、资源和人物关系；不创建云账号，不请求地理位置，不查询现实天气。

## 时间与天气

当前家园采用设备本地时间：05:00—08:59清晨，09:00—16:59白天，17:00—18:59黄昏，其余时间为夜晚。背景光线、晨昏色调与夜晚光晕随之改变。

模拟天气包含晴朗、多云、小雨、微风，依据存档创建时间、本地日期与每10分钟时段稳定生成。同档同段天气一致，回到游戏不重新随机。天气可连续相同，不承诺每段都不同。房间雨/风只出现在窗区；庭院与花园显示室外雨线、风线与云层动画。界面明确标为“游戏内模拟天气”。

场景下方显示时间/时段/天气和两熊当前活动，可点“时段”“天气”预览不同环境，再点“跟随时间”恢复自动。预览只影响当前页面，不改存档与茶会配方；历史回忆和茶会演出不借用当前时钟，保留原场景设定。

## 自主活动与GIF

两熊按90秒闭合路线活动，坐标连续衔接。使用现有走路图集逐帧切换，靠近已经解锁且实际摆放的书架/画架/坐垫或椅子后读书、画画、歇息；尚未解锁则看看风景，不提前使用不存在的家具。其他动作包括一起整理、会合贴贴。

从用户动作包92个GIF中选出透明、无文字的4组：贴脸依偎、亲脸、布布弹吉他、一二喝茶。原GIF复制使用，未重绘人物；另存首帧PNG供静态场景和合照使用。合体GIF原画为近景半身，因此采用场景中的圆角互动小画面，保留两熊在家中会合的完整人物，避免半截人物悬在地面。歇息段用弹吉他/喝茶动画；吉他GIF没有音轨，不宣称新增了吉他声音。

仅当前可见家园每200毫秒更新活动中的演员/道具位置与变化的姿势，不反复重建棋盘或家具。同一GIF持续播放期间保持其节点，避免每一帧重新加载。正在选择/移动家具、聊天、读剧情、查看弹窗、合成拖动或页面隐藏时暂停自主更新。开启“减少动态”后停止自主闲逛和天气动画，保留环境展示及原静态人物。

静态发布与离线HTML都包含4组GIF和4张首帧PNG，共65项运行资源。合照冻结当前布局、环境与动作描述，GIF使用静态关键帧，后续导航不改变照片内容。素材来源、尺寸、时长与检视证据见 `art/actions-v1.3.json`。

## 布置入口

场景“可以布置啦”与下方“前往布置”共用 `openBuildPlacement`。已交付材料时定位实际区域并打开原配色/确认布置窗口；未交付时返回当前主线合成提示。保留原确认过程，不自动选颜色或额外扣费。按钮有明确触控区域和更高层级，天气、角色与GIF不遮挡操作。
