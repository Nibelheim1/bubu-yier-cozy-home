# v1.5 角色独立活动、GIF与过门

2026-10-10。家园中布布、一二各有唯一场景归属和位置；镜头切到另一处不会把角色复制或搬过去。新游戏和缺位置字段的旧存档，布布在小屋(28,65)、一二在小屋(74,70)，初始站位分开。保留数值、合成页、三处独立夜景和小事静态结果图。

## 状态与动作规则

- `residents`只保存两人的region/x/y。动作、倒计时、路径、配对和指针捕获只存在于运行控制器，读档不会恢复半次拖动。存档schema仍为2，旧档缺字段自动补齐；已有非法区域、非有限坐标或越界位置拒绝导入。
- 两熊分别随机选择行走目标、停留和动作。家园全景及其他区域切镜头不复制演员；同一控制器驱动所有当前居民，描述场景或拍照不再次推进时钟。
- 37个原GIF分为28单人随机、4双人互动、4角色专属拖动、1寻人。全部接入合适的状态队列，原素材未改。室内工作/休息/游戏只在小屋；秋千、骑鹅、木马只在户外；洗衣在庭院；其他通用动作内外均可。详细分类见 `src/actor-actions.mjs` 和 `art/actions-v1.5.json`。
- 每个角色每个场景的随机动作按洗牌队列消费；靠近桌子、软垫或椅子时，优先从队列中选择对应工作、就餐或休息动作，其他动作仍能轮到。GIF自带临时配件，不新增永久家具或伪造解锁。
- 分场时，一二选择动作有70%概率使用“人呢”，仍会散步和播放其他动作；同场时不从随机队列抽取“人呢”。
- 同场且距离小于18个场景百分点，两人处于停留或行走时，随机检查可能触发亲亲、壁咚、打布布或贴贴。每次显示5秒，结束/打断后12秒冷却。双人图只绘制一张，隐藏单人图但保留两人各自命中区；“打布布”按上方一二、下方布布命中，其他三个按左右命中。
- 暂停、隐藏页面和减少动态不补跑停掉的时间。减少动态显示静态居民；手动拖动仍显示对应拖动GIF。短GIF完整循环数秒，一次性骑鹅保持原单次播放行为。

## 长按与出口

长按420毫秒后才拖动。未达到时限提前移动超过8像素会取消；短点仍聊天。拖中按角色目录随机选被拖动1/2，不能以文件编号猜角色。拖动捕获在稳定的场景容器，换GIF或打断互动不会丢失捕获。

门口松手转移被拖的这一只，并让镜头跟随；其他角色保留原场景。出口有常驻小标签，拖动时亮出范围，命中后变绿。

松手到非门位置会保存该位置，短暂停留后恢复活动。取消、切页、弹窗、失去捕获、窗口失焦或重置时恢复拖前位置。自动保存也回写拖前位置，未松手的预览不进入存档；导入/重置会重建控制器，避免继续修改旧存档对象。

## 与原玩法衔接

两熊必须同在活动目标场景才能一起做小事、结算茶会或迎接小栗。未到齐时界面提示，引擎也在消费/奖励之前拒绝操作，防止两熊分场却突然演出在一起。每日一次和原有奖励规则保持。旧回忆、剧情角色卡和茶会重播是历史展示，不会改变当前家园居民位置。

合照采用当前场景演员快照：只出现这里的居民，双人图不额外画两只命中区域。提供素材原件和历史制作来源保留；旧四组家园GIF及对应静帧不再进入当前运行包。
