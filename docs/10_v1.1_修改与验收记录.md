# v1.1 修改与验收记录

2026-10-08。新版本目录为 `bubu-yier-cozy-home-v1.1`，相邻原版保留。当前交付是本地修改和构建，未上传或发布 TapTap。

## 已落地的改造

- 家园分成暖暖小屋、晴天小花园、门前小庭院；全景可横向拖动，区域也有直接入口。
- 原有24件装修按12/6/6分配到三处，完成后才显示。家具沿边布置，中央为角色留出活动空间；只有茶杯与茶桌、坐垫与地毯有意叠放。
- 三处每天各有一次陪伴活动，复用金币和体力，每次奖励8金币与5体力；同一地区累计三天可收集永久日常回忆。同日重复点击不重复奖励。
- 36种合成物、6个工作台、24件装修全部使用新生图，采用更明亮的粉红、青蓝、柠檬黄和绿色，圆润的3D体积、高光与夸张造型。
- 三张区域背景和全景重新生成；背景保留建筑、边缘植被与空场地，装修通过进度独立摆放。
- 新双熊聚会纪念图、一二休息姿势均同时附带两张角色卡生成。其余新增素材不含布布一二。角色卡和用户色彩参考原件均保留。
- 合成加入飞入、落地弹跳和星光反馈，首次发现四级以上物品显示更大的收藏卡；尊重减少动画设置。
- 照片导出使用当前区域、当前角色姿势、装修进度和配色；图集通过源槽位等比绘制。

## 同步修复

- 邻里委托提示跟随当前委托，主线完成后继续可用。
- 新链首次章节礼物给出两个一级材料，保留玩家第一次亲手合成。
- 待领礼物满时章节礼物排队保存，取出后补入；旧超限礼物存档能够迁移。
- 旧版存档迁移补上区域与互动字段，保留主线、棋盘、仓库等进度。
- 图集采用方形SVG视窗等比显示，矩形界面槽位不会拉长图像；源图通过生图返修增加留白。

## 验证证据与边界

- `npm test`：43项通过，包括新手合成→交付→布置、旧存档迁移、区域每日互动、重复领取、跨日回忆、满队列章节礼物，以及合法操作推进24项主线与发现36种物品。
- `npm run build`：构建成功，产出 `dist/` 和完整内嵌资源的离线单文件；11张图集、6张世界/角色新图进入运行包。
- `node --check dist/app.js`：构建后的脚本语法通过。构建后另执行单文件相关检查，选择器、内嵌标志和脚本占位符检查通过。
- 新生成图已逐张原生视觉复核；图集尺寸1536×1024，包含透明通道。尺寸和透明元数据见 `qa/asset-metadata.json`，生成来源和参考记录见 `art/generation-v1.1.json`。
- **实际浏览器操作与手机界面验收未完成**：内置浏览器访问本地预览时拒绝操作，原因是无法验证已保存的浏览器权限。未通过其他浏览器控制或间接方式绕过。因此不能把上述规则、构建和原图复核称为真实页面或真机验证通过。
- 未验证Android/iOS真机、TapTap宿主、广告、排行榜或云存档。此次也未接入这些功能。
- 离线单文件包含高分辨率原始素材，体积49.56MiB，当前便于本地体验；上线前仍需根据实际宿主的加载体验做素材体积优化和真机验收。

## 使用入口

根目录 `启动新版v1.1.bat` 或新版目录 `双击开始游戏.bat` 可打开 `release/好日子小屋_双击即玩.html`。开发预览在新版目录运行 `npm start`。本次保留的预览服务使用4188端口。

旧存档可从原版设置导出，再在新版设置导入。新版迁移已通过规则检查，浏览器导入流程仍包含在待完成的页面验收中。
