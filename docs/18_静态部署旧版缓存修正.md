# 静态部署旧版缓存修正

日期：2026-10-09，游戏版本仍为1.2.1。

从GitHub重新拉取main后，确认原提交 `0cc3318` 中package、构建记录均为1.2.1，包含棋盘交互模块、家具移动和文案修正，未误上传v1.1。本次继续更新同一main分支，不替换已有提交历史或旧标签。

发现旧版缓存兼容缺陷：v1.0/v1.1使用 `cozy-` 缓存，新版只清理 `cozy-v12-` 缓存；通用 `caches.match` 又遍历所有缓存，因此可以命中遗留程序。

修正：

- 激活新离线缓存时清理遗留游戏缓存，保留当前缓存及其他应用缓存。
- 资源和离线入口仅从当前构建的缓存读取。
- HTML中的程序、样式链接携带构建标记，并与预缓存列表一致。
- 安装预缓存绕过浏览器HTTP缓存；Service Worker注册禁用更新脚本的HTTP缓存并请求检查更新。
- 不修改存档、人物、玩法和奖励；不清理Local Storage。

`node scripts/build.mjs` 构建成功；`node --check dist/app.js` 通过。`node --test tests/deployment-cache.test.mjs` 的3项检查通过，覆盖旧缓存清理、只读当前缓存、版本链接与预缓存请求。这是生成脚本的行为检查，不是浏览器或腾讯云线上验收。

腾讯云部署应上传当前dist内全部内容至网站根目录，或将自动部署发布目录设为dist。仅在GitHub更新文件不会替代腾讯云手动部署。尚未取得托管网址，不能确认腾讯云源站、CDN或用户浏览器的实际版本；云端独立CDN仍需按配置刷新。
