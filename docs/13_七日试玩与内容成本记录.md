# v1.2七日试玩与内容成本记录

状态：材料已准备，尚未招募或记录真人玩家。以下是观察方法，不是留存成果。

先用5—8位目标玩家观察首合、首交付、首次布置、生产器教学、补给理解、动作推进和照片导出。记录具体卡点及玩家原话；不要把这组定性反馈估成商业留存。

基础障碍修好后，再选同一来源的一小批真实玩家连续观察七日。固定版本，记录匿名玩家ID、进入日期、茶会解锁日期、每天是否真正游玩和具体行动、失访与原因。保留正常中断和跳天，不临时增加连续登录大奖。

分别计算首次进入次日/第七日的D1/D7，以及已经解锁茶会后的再次游玩。全体与解锁人群分别给分母，未解锁者不能算体验了茶会。D7观察窗口未满时标记未成熟，失访如实保留。D30必须实际等待，不能外推。

反馈检查点：玩家能否解释为什么选这个方案；第二次是否主动换方案；领完奖励是否还看家园/换摆法/重温；六款纪念物收齐后是否仍愿重办；是否记住小栗的下次约定。奖励驱动和生活/关系驱动分开记录。

`14_玩家观察模板.csv`为逐日观察空表，`15_内容制作成本模板.csv`为内容工时空表；均无模拟玩家行、留存百分比或虚构工时。记录对白、纪念物、角色帧及运行接入的实际工作时间，决定下一轮是否有可持续供给能力。

当前版本完成后先检查这一个茶会循环。愿意主动重玩且制作成本可持续时，再增加一个生活主题；主要为奖励回来时，先改选择与画面回报。有限六组内容不宣称无限耐玩或已解决90日留存。
