# 完整游戏设计 v1.0
## 一句话
把两只熊的小愿望合在一起，让一间空屋慢慢长成家。

## 产品与体验
中文竖屏，360–480 CSS 像素优先；桌面居中手机画幅。无需账号、无付费、无远程运行依赖。主入口“开始我们的好日子”→可跳过和重看的四幕开场→第一个合成→交付→门垫修缮→正常循环。支持鼠标拖动、触摸拖动、点选后点目标、键盘焦点与按钮操作。

## 状态与货币
49 格棋盘，6 个不可丢弃的固定工作台；末两行逐步解开。6 类物品各 6 阶。心愿星只由当前主线订单产生并用于对应改造；金币用于工作台升级、仓库扩容与便利道具；体力用于产出，自动恢复，有免费茶歇与可选无限体力的轻松模式。没有只能付费补救的资源。

生产消耗 1 体力与 1 库存；合成不消耗体力；工作台产物只来自本条链，普通产出 80% 一阶 / 20% 二阶，升级提高二阶概率与库存。教程产出固定。物品价值由 2^(level-1) 定义。每次二合价值守恒；拆分也严格守恒。订单按精确阶数消耗；不能用高阶“猜测抵扣”低阶。

## 主线框架
6 章 × 4 个改造，总计 24 个不同订单与改造。章节：先把门打开；热乎乎的下午；给想象留个角；窗边会开花；不赶时间的晚上；今天请你来坐坐。每项改造有前置愿望、明确实物需求、交付对白、两种配色选择和落地位置。每章完结奖励一张回忆与资源。末章有完整结尾，回到自由经营。

主线任务读取数据表；主线交付只能一次；改造须有本阶段交付许可且有心愿星；改造后推进 stage，释放下一任务。不能在同一订单双击领取，不能把金币花光导致主线停止。工作台自动解锁时不占用新格。

## 辅助系统
邻里委托：两张可刷新、只要求当前已解锁来源的订单，完成后换新；不消耗主线许可。
图鉴：可追溯全链和产地，发现状态随存档保存；新物品首见提示。
仓库：初始 8 格，扩到 24 格；移动须先校验空间；礼物待领取队列在满盘时保留。
救济：出售 / 回收、撤销上次移动或合成或出售、拆分剪刀、手动整理、智能提示、产地跳转、免费茶歇。不能出售或拆掉生产器。
每日：以本机自然日计，三项可重复达成的目标分别为合成、交付、产出；仅领取按钮发奖，无重复领取。设备改时钟不提供联网防作弊保证。
设置：音效、轻音乐、减少动态、轻松模式；本地存档自动备份，JSON 导入导出，重开须二次确认。

## 美术与交互
奶油纸、焦糖描边、鼠尾草绿主按钮、杏粉提示、纸胶带与手帐小章。真实绘图 PNG/WebP 作为角色、合成物品、工作台、装修与环境素材；功能小图标可矢量绘制，但不用 emoji 替代游戏物品。识别靠轮廓和具体物体，不靠数字/颜色换皮。

所有角色相关图以用户参考图为输入或来源，保留原始图、生成原图与切图记录；素材生成失败不冒称成功。 UI 中使用的人物立绘需人工对照：色块、耳朵、脸、领结、体型、四肢、裁切和透明边缘。

## 技术架构
纯浏览器 HTML/CSS/JavaScript，规则与 DOM 分离，数据驱动任务；规则模块可在 Node 中独立测试。构建生成多文件静态站和图片内嵌的单 HTML 离线版；构建不依赖网络。资源预加载失败提供错误提示而非假进度；页面切后台立即保存，恢复时计算资源。最小文件存档 schema 校验，错误存档不得覆写当前有效状态。
