# 布布一二 · 好日子小屋 v1.1.0

新版在独立目录 `bubu-yier-cozy-home-v1.1/` 中开发。相邻的原版 `bubu-yier-cozy-home/`、原版素材和原版 QA 记录没有被覆盖。

## 运行入口

构建完成后，打开本目录的 `release/好日子小屋_双击即玩.html`，或运行本目录的 `双击开始游戏.bat`。单文件版内嵌图片、音乐和代码；使用现代浏览器打开即可游玩。附件预览不等于运行完整网页。

手机和静态网站使用本目录的 `dist/`。开发预览需要 Node.js 18 或更新版本，没有 npm 依赖：

```sh
npm run build
npm start
```

本机服务默认地址为 `http://127.0.0.1:4173`。构建必须在新版生成素材齐备后执行；缺少任一新图时会报告对应名称，避免输出缺图版本。

## 这一版的变化

家园分成小屋、小花园、门前庭院三个区域，通过家园地图切换。装修分散到对应空间，保留角色活动和画面留白；室外布置与原有心愿进度相连。六章、24 个心愿以及清洁、修缮、烘焙、茶点、手作、园艺六条合成链仍是游戏的核心。

36 个合成物、6 个工作台和24件装修换成更鲜明、夸张且有体积感的新素材。每张透明图集包含3列、2行的六个素材；界面和照片导出直接读取整张图集的槽位及透明内边距，不改色、不裁出新文件，也不重复内嵌被替代的旧 PNG。普通角色、通用按钮和音乐继续使用已有资源。新增角色图的双角色卡参考记录见 `art/generation-v1.1.json`。

新背景包括 `region-house.png`、`region-garden.png`、`region-courtyard.png` 和 `world-map.png`。包含布布一二的新图以用户提供的角色卡为身份参考；色彩参考本次用户提供的庭院聚会图。旧的 `home-background.png` 和被替代的独立物品图仍可保留在素材源目录，但不进入新版运行包、预载或离线缓存。

## 存档迁移

原版进度可在原版的“设置 → 导出存档”保存为 JSON，再从新版设置导入。新版沿用原有物品 ID 和主线进度结构；新增区域使用同一主线的装修记录，不要求重新开始。建议先保留原版导出的文件。

浏览器进度仍保存在本地。切换浏览器、换设备或清理站点数据前先导出；单文件的本地持久化能力取决于浏览器。当前没有账号、云存档或平台 SDK。

## 文件说明

| 路径 | 用途 |
|---|---|
| `release/好日子小屋_双击即玩.html` | 构建生成的离线单文件入口 |
| `dist/` | 构建生成的静态网站部署文件 |
| `src/visuals.mjs` | 图集 ID 映射和照片绘制接口 |
| `src/data.mjs`、`src/engine.mjs` | 故事、区域布置数据和规则 |
| `src/ui.mjs`、`src/style.css` | 三区域界面与合成视觉反馈 |
| `public/assets/` | 新生成图与保留的旧素材原件 |
| `art/reference/` | 用户提供的角色卡原件 |
| `release/build-info.json` | 当前构建版本与运行素材数量 |
| `qa/`、`docs/`、`review/` | 历史验证、设计和审查资料；旧记录不代表新版验收 |

图集命名：六条链分别为 `atlas-clean/tools/bake/tea/craft/garden.png`，工作台为 `atlas-generators.png`，装修为 `atlas-decor-a/b/c/d.png`。合成链与工作台从左到右、从上到下排序；四张装修图对应01–06、07–12、13–18、19–24。槽位保持方形，透明留白参与显示，避免拉伸原图。

## 验证与发布边界

本次新版43项相关检查通过，构建和构建脚本语法检查通过；原始新图逐张视觉复核。实际页面与手机操作验收因内置浏览器无法验证本地预览权限而未完成，详见 `docs/10_v1.1_修改与验收记录.md`。原版历史检查不能当作 v1.1 的测试结论。当前离线单文件49.56MiB；上线前仍需实际加载体验、素材体积和真机验收。此版本未上传或发布 TapTap。

```sh

```
