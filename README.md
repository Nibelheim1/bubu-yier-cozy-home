# 布布一二 · 好日子小屋 v1.2.1

本次修正版：点击不同棋盘物品只切换选中，点击同类同级物品合成；长按约0.36秒，物品浮起后拖动移动/交换。在小屋、花园、庭院点击已布置家具后，按住“移动”拖动，松手保存，可恢复原位。位置随存档和合照保留，茶会回忆使用当时的布局。

全部运行文案与阶段、材料、来客和实际动作重新核对，并同步修复旧存档已保存的错误对白。修改与验证见 `docs/17_v1.2.1_修改与验收记录.md`，逐项文字对照见 `docs/16_v1.2.1_文字审校记录.md`。仍使用v1.2存档键与schema2，升级保留现有进度。

本版主题“小栗来坐坐”。保留三处家园、49格棋盘、六条六阶合成链和六章24项主线，增加可重玩的茶会与永久小纪念。两熊维持权威角色卡的平面插画风格；小栗是独立设计的灰蓝松鼠，不使用两熊参考卡。

## 开始游戏

双击本目录的 `双击开始游戏.bat`，或打开 `release/好日子小屋_双击即玩.html`。工作区外层也有 `启动新版v1.2.bat`。离线HTML完整内嵌代码、图片与音乐，游戏运行不调用生图服务。

静态部署和手机浏览使用 `dist/`。本地预览需要Node.js18以上，没有npm依赖：

```sh
npm run build
npm start
```

默认预览地址 `http://127.0.0.1:4173/`。不要将附件预览当成完整运行网页。

## 本版玩法

- 日常活动随杯子、幼苗与茶点实际准备进度变化。新日常回忆同时需要累计三天陪伴和对应生活节点；旧已收集回忆保留。
- 新工作台首次教学要求实际取出一次材料。心愿补给先选择订单和缺材料的来源，展示四件内容，再确认购买。
- 第23项分两步、第24项分三步准备，途中保存并在场景展示。主线仍为24项，原整单配方、奖励和心愿星保持原值。
- 完成第13项并认识全部工作台后，两熊可办茶会。暖心茶点/花园小聚两个方案配合晴日/留纪念/有风三个状况，可自由换方案，不要求连续登录。每轮基础奖励28金币、3体力、12经验，没有心愿星。
- 三类小物共六款永久收藏；小屋、花园和庭院各一个可替换纪念位。首次茶会保存参与者、准备方案、配色、装备和防风选择，可在手帐重看。
- 主线结束后确认迎接小栗，观看走入、摆杯、端茶与递杯。此后新茶会才加入小栗。动作可分步操作、跳过和重看；跳过或中断不重新扣物、发奖。
- 合照绘制当前实际场景、参与者、道具和所选纪念物。点击照片时冻结场景，随后导航不会改变照片内容。

## 保留与迁移

相邻原版和v1.1目录、其素材、评审和未提交文件保留。新版使用独立存档键 `bubu-yier-cozy-home-v1.2`，同一来源首次进入可只读复制旧键 `bubu-yier-cozy-home-v1`；所有新版写入只作用于新键。清空新版不再自动复活旧进度。

不同浏览器、设备或文件来源需要从旧版“设置→导出存档”保存JSON，再在新版导入。存档schema为2，应用版本为1.2.1；迁移不重发主线、章节和图鉴奖励。旧已交付终章不要求重新交材料。

浏览器本地保存与实际下载能力仍需在使用的浏览器确认。设置提供保存失败反馈、JSON导出和导入确认；当前没有账号、云存档或平台SDK。

## 文件与素材

`src/data.mjs`、`src/engine.mjs`负责真实结果；`src/scenes.mjs`统一演出与照片场景；`src/visuals.mjs`负责图集槽位；`src/ui.mjs`、`src/style.css`负责交互。静态和离线构建均读取真实PNG宽高，以原图槽位等比绘制，不程序重绘人物原图。

`art/generation-v1.2.json`保存完整生成提示、参考、原始输出和采用/废弃记录。新素材由内置image_gen生成，原件复制入项目；小栗仅参考独立的新角色卡。旧脚本和文档属于历史记录，见 `docs/00_历史资料说明.md`，不用于宣称v1.2通过验收。
