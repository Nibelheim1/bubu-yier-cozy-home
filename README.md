## 开始游戏

双击本目录的 `双击开始游戏.bat`，或打开 `release/熊熊之家_双击即玩.html`。工作区外层也有 `启动新版v1.2.bat`。离线HTML完整内嵌代码、图片与音乐，游戏运行不调用生图服务。

静态部署和手机浏览使用 `dist/`。本地预览需要Node.js18以上，没有npm依赖：

```sh
npm run build
npm start
```

默认预览地址 `http://127.0.0.1:4173/`。不要将附件预览当成完整运行网页。

## 腾讯云静态托管部署

上传本目录 `dist/` 内的全部内容，让 `index.html`、`app.js`、`style.css`、`sw.js`、`manifest.webmanifest` 和 `assets/` 位于同一网站根目录。GitHub自动构建的发布目录也应设置为 `dist`，构建命令为 `npm run build`。不要选相邻v1.1目录或旧标签；当前分支为 `main`。

2026-10-09追加修正旧版离线缓存兼容：新程序仅读取本次构建缓存，清理遗留 `cozy-` 游戏缓存，入口的程序/样式链接携带构建标记。更新不会清除游戏的Local Storage存档。更换文件后关闭游戏再重新打开，并在设置底部确认 `v1.4.1`。若使用单独的CDN，需同时按托管配置刷新入口及更新资源的云端缓存。本轮是本地修改与构建，未上传GitHub或腾讯云，不能据此宣称线上已更新。

## 本版玩法

- 日常活动随杯子、幼苗与茶点实际准备进度变化。新日常回忆同时需要累计三天陪伴和对应生活节点；旧已收集回忆保留。
- 新工作台首次教学要求实际取出一次材料。心愿补给先选择订单和缺材料的来源，展示四件内容，再确认购买。
- 第23项分两步、第24项分三步准备，途中保存并在场景展示。主线仍为24项，原整单配方和心愿星保持；主线金币为18+3M，XP为10+floor(M/3)，布置加15XP，M是一级等价材料质量。合成不再加XP。
- 完成第13项并认识全部工作台后，两熊可办茶会。暖心茶点/花园小聚两个方案配合晴日/留纪念/有风三个状况，可自由换方案，不要求连续登录。六种配方均为8质量，每轮奖励32金币、12经验，没有心愿星或体力。
- 三类小物共六款永久收藏；小屋、花园和庭院各一个可替换纪念位。首次茶会保存参与者、准备方案、配色、装备和防风选择，可在手帐重看。
- 主线结束后确认迎接小栗，观看走入、摆杯、端茶与递杯。此后新茶会才加入小栗。动作可分步操作、跳过和重看；跳过或中断不重新扣物、发奖。
- 合照绘制当前实际场景、参与者、道具和所选纪念物。点击照片时冻结场景，随后导航不会改变照片内容。

## 保留与迁移

相邻原版和v1.1目录、其素材、评审和未提交文件保留。新版使用独立存档键 `bubu-yier-cozy-home-v1.2`，同一来源首次进入可只读复制旧键 `bubu-yier-cozy-home-v1`；所有新版写入只作用于新键。清空新版不再自动复活旧进度。

不同浏览器、设备或文件来源需要从旧版“设置→导出存档”保存JSON，再在新版导入。存档schema为2，应用版本为1.4.1，独立economyVersion标记新数值迁移；迁移保留人物等级并按比例转换升级进度，不补发升级体力、主线、章节或图鉴奖励。旧已交付终章不要求重新交材料。旧体力点心每个一次性转20金币；旧能量高于100截到100；轻松模式字段删除。

浏览器本地保存与实际下载能力仍需在使用的浏览器确认。设置提供保存失败反馈、JSON导出和导入确认；当前没有账号、云存档或平台SDK。
